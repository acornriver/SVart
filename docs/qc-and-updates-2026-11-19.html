QC 검증 결과와 최근 업데이트 (11/19)

2026-11-19 기준. 아이패드 앱(SVart, 개발 브랜치)과 청감타워(SVartTower, 현재 배포본)를 전체 점검한 결과와, 11/17 공유 문서 이후의 업데이트를 정리했습니다.

요약

  • 자동으로 확인할 수 있는 범위는 모두 통과했습니다. 실패한 항목은 브라우저가 자동으로 찾는 아이콘 파일(favicon)이 없다는 것 하나로, 동작에는 영향이 없습니다.
  • 아이패드에서 보낸 달팽이가 타워 TV에 실시간으로 도착하고, QR로 연 휴대폰에서 같은 코드·같은 색으로 나오는 것까지 한국어·영어 모두 확인했습니다(시험용 DB 사용).
  • 전시 전에 정해야 할 것이 두 가지 나왔습니다: 운영 DB에 남은 테스트 달팽이 21마리, 타워에서 15~17kHz 달팽이가 한곳에 몰리는 문제(4장).
  • 아이패드 실기기, 헤드폰 청취, 실제 휴대폰 카메라로 QR 찍기는 사람이 직접 확인해야 합니다.

4. 전시 전에 정해야 할 것

발견내용선택지
운영 DB의 테스트 달팽이 21마리개발 기간(11/09~11/13)에 보낸 문서가 운영 DB에 남아 있어, 전시 첫날 타워 TV와 모바일 목록에 그대로 나옵니다. 모두 달팽이 색이 생기기 전의 문서라 무지개 색이 아닙니다.숨기기(복구 가능) / 그대로 두기
15~17kHz 달팽이 몰림21마리 중 15마리가 15~17kHz라 타워의 같은 높이에 겹칩니다. 빛이 더해져 하얗게 번지고 코드 이름표가 겹쳐 읽히지 않습니다. 실제 성인 관람객도 이 범위에 몰릴 가능성이 큽니다.몰린 구간을 더 넓게 펼치기 / 겹칠 때 빛·이름표 줄이기 / 그대로 두기
