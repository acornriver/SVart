# 전시장 설치 안내 · 아이패드와 청감타워 TV

2026-11-22 기준. 전시장에서 아이패드 미니 5(관람객용)와 청감타워 TV를 켜고, 관람객이 앱 밖으로 나가지 못하게 잠그는 방법입니다. iPadOS 버전에 따라 메뉴 이름이 조금 다를 수 있습니다.

## 한눈에

| 항목 | 내용 |
| :--- | :--- |
| 아이패드 앱 주소 | https://acornriver.github.io/SVart/ |
| 청감타워 TV 주소 | https://allearsare.love/wall/ |
| 관람객 휴대폰 주소 (QR로 열림) | https://allearsare.love/ |
| 아이패드에서 쓰는 앱 | Kiosk Pro Lite (주소창 없이 웹페이지를 전체 화면으로 띄움) |
| 앱 밖으로 못 나가게 | iPad 기본 기능 '사용법 유도'(Guided Access) |
| 화면 방향 | 가로 전용 (세로로 들면 '가로로 돌려 주세요' 안내가 덮음) |

## 1. 처음 한 번만 하는 아이패드 설정

### 1-1. 화면이 꺼지지 않게

- **설정 → 디스플레이 및 밝기 → 자동 잠금 → 안 함**
- **설정 → 손쉬운 사용 → 디스플레이 및 텍스트 크기 → 자동 밝기 끔**, 그리고 밝기를 원하는 값으로 고정
- **True Tone, Night Shift 끔** (설정 → 디스플레이 및 밝기). 화면 색이 시간에 따라 바뀌지 않게
- **저전력 모드 끔** (설정 → 배터리). 전시 중에는 충전기를 계속 꽂아 둡니다

### 1-2. 방해받지 않게

- **집중 모드(방해 금지) 켬**: 알림·전화·메시지 팝업이 화면을 가리지 않게
- **설정 → 일반 → 소프트웨어 업데이트 → 자동 업데이트 끔**: 전시 중 갑자기 재시동되지 않게
- **설정 → 일반 → 백그라운드 앱 새로 고침 끔** (선택)
- 알림을 보내는 앱(메시지, 메일 등)의 알림을 꺼 두면 더 안전합니다

### 1-3. 소리

- 헤드폰을 연결해 둡니다(블루투스라면 아이패드마다 자기 헤드폰 한 개만 연결)
- **설정 → 사운드 및 햅틱 → 헤드폰 안전 → '큰 오디오 줄이기' 끔**: 켜져 있으면 iPad가 음량을 저절로 줄여 검사 소리 크기가 달라집니다
- 아이패드 본체 음량은 미리 정한 값으로 맞춘 뒤 사용법 유도에서 볼륨 버튼을 꺼 고정합니다(2장)
- 앱 안의 '안내 음량' 슬라이더는 관람객이 조절할 수 있고, 다음 관람객에게는 처음 값으로 돌아갑니다

### 1-4. 사용법 유도(Guided Access) 켜기

1. **설정 → 손쉬운 사용 → 사용법 유도** → 켬
2. **암호 설정 → 사용법 유도 암호 설정**: 관리자만 아는 숫자 암호를 정하고 따로 적어 둡니다(Touch ID 사용은 꺼 두는 편이 안전)
3. **시간 제한**: 알림 소리 없음
4. **디스플레이 자동 잠금**: 안 함
5. **손쉬운 사용 단축키**(같은 화면 아래)가 '사용법 유도'로 되어 있는지 확인합니다. 아이패드 미니 5는 **홈 버튼을 세 번 빠르게 누르면** 사용법 유도가 시작·종료됩니다

### 1-5. Kiosk Pro Lite 설치와 주소 설정

1. App Store에서 **Kiosk Pro Lite**를 설치합니다
2. 앱의 설정에서 시작 페이지(Homepage)를 **https://acornriver.github.io/SVart/** 로 넣습니다. 설정 위치는 앱 버전에 따라 앱 안 설정 화면 또는 iPad '설정' 앱의 Kiosk Pro 항목입니다
3. 주소창·뒤로 가기 같은 브라우저 도구 막대가 보이지 않게, 그리고 화면이 가로로 꽉 차게 설정합니다
4. 앱 설정에 '일정 시간 뒤 시작 페이지로 돌아가기'가 있으면 **끕니다**. 앱이 스스로 2분 방치 시 첫 화면으로 돌아가므로 겹치면 검사 중에 끊길 수 있습니다
5. 앱을 처음 열 때 소리·네트워크 관련 권한을 물으면 허용합니다

## 2. 매일 개관 전에 하는 일

1. 아이패드가 충전 중이고 와이파이에 연결돼 있는지 확인합니다
2. 헤드폰 전원을 켜고 연결됐는지 확인합니다
3. **Kiosk Pro Lite를 열고 페이지를 새로 불러옵니다**(하루 한 번 새로고침하면 메모리가 깨끗해집니다). 첫 화면에 '모든 귀는 [ ] 이다' 제목이 보이면 됩니다
4. 가로 방향으로 놓습니다
5. **홈 버튼을 세 번 빠르게 눌러 사용법 유도를 시작**합니다. 처음 한 번은 아래 옵션을 맞춥니다(다음부터는 기억됨)
6. 직원이 한 번 끝까지 검사해 보고, 소리가 나는지, 마지막에 달팽이를 밀어 보낸 뒤 청감타워 TV에 도착하는지 확인합니다

### 사용법 유도 옵션 (시작 화면 왼쪽 아래 '옵션')

| 옵션 | 설정 | 이유 |
| :--- | :--- | :--- |
| 잠자기/깨우기 버튼 | 끔 | 관람객이 화면을 끄지 못하게 |
| 음량 버튼 | 끔 | 검사 소리 크기를 일정하게 유지 |
| 동작 | 끔 | 아이패드를 돌려도 화면이 세로로 바뀌지 않게 |
| 키보드 | 끔 | 앱에서 키보드를 쓰지 않음 |
| 터치 | 켬 | 검사를 하려면 반드시 켬 |
| 시간 제한 | 끔 | 전시 내내 유지 |

화면 일부를 손가락으로 동그라미 쳐 터치를 막는 기능은 쓰지 않습니다. 앱 화면 전체를 써야 합니다.

## 3. 문제가 생겼을 때

| 증상 | 조치 |
| :--- | :--- |
| 화면이 멈추거나 소리가 안 남 | 홈 버튼 세 번 → 암호 입력 → 사용법 유도 종료 → Kiosk Pro에서 페이지 새로고침(안 되면 앱을 완전히 닫았다 다시 열기) → 홈 버튼 세 번으로 다시 시작 |
| 헤드폰에서 소리가 안 남 | 헤드폰 전원·연결 확인. 사용법 유도를 잠깐 끄고 제어 센터에서 출력 장치가 헤드폰인지 확인 |
| 앞사람이 중간에 그만두고 감 | 그대로 두면 2분 뒤 첫 화면으로 돌아갑니다 |
| 와이파이가 끊김 | 검사와 감상은 계속됩니다. 보낸 달팽이는 아이패드에 쌓였다가 연결되면 자동으로 올라갑니다 |
| 영어로 바뀐 채로 남음 | 영어 관람객 다음에는 첫 화면이 영어로 남습니다. 첫 화면 오른쪽 위에서 '한국어'를 누르면 됩니다 |
| 암호를 잊어버림 | 사용법 유도는 암호 없이는 끌 수 없습니다. 암호는 반드시 따로 적어 두세요(잊으면 아이패드를 강제로 재시동해야 함) |

## 4. 청감타워 TV

- TV에 연결한 컴퓨터의 브라우저(크롬 권장)로 **https://allearsare.love/wall/** 을 엽니다
- 키보드 **F**를 누르면 전체 화면이 됩니다. 마우스 커서는 저절로 숨겨집니다
- 화면은 매일 **새벽 5시에 스스로 새로고침**됩니다. 컴퓨터 절전·화면 보호기는 꺼 둡니다
- 키보드 **D**: 상태 확인 창(관리자용), 다시 D로 닫음. **R**: 달팽이 비우기(누르지 않도록 주의)
- 새 달팽이가 도착하면 포탈이 열리고 카메라 쪽 자리에 나타납니다
