11/15 작가 지시 이후 변경 사항과 QC 결과

2026-11-17 기준. 원우리 작가의 11/15 지시(감상 화면 버튼, QR 화면, 달팽이 색, 포탈)를 반영한 내용과 그 뒤의 변경, 11/16~17에 진행한 QC 결과를 정리했습니다.

요약

  • 작가 지시 다섯 가지는 모두 반영했고, 11/15에 운영 서버(Firebase Hosting)와 청감타워(GitHub Pages)에 배포했습니다.
  • QC는 자동 테스트로 가능한 범위를 모두 통과했습니다. 전체 흐름(한/영), 관람객 연속 6명, 실제 터치 입력, 방치 리셋, 전송(온라인·와이파이 끊김), QR → 휴대폰 화면까지 확인했습니다.
  • QC 중 버그 네 개를 찾아 고쳤습니다. 이 수정은 아직 커밋·배포하지 않았습니다(개발 브랜치 작업본에만 있음).
  • 아이패드 실기기, 헤드폰 청취, 실제 휴대폰 카메라로 QR 찍기는 확인하지 못했습니다. 사람이 직접 해 봐야 합니다.

1. 작가 지시(11/15) 반영

지시반영한 내용상태
감상 화면 버튼에 곡 제목을 작게작가 이름 아래에 곡 제목을 작게 적음: 원우리 <전극 응답> / 펠릭스 쿠빈 <반짝이는 레지스터> / 원우리 × 펠릭스 쿠빈 <레지스터 응답>. 영어는 Adaptive Response / Scintillating Registers / Register Response배포됨
북서울 소리도 '… 소리'로 표기아랫줄 세 버튼을 '당현천 소리 / 중계역 지하철 소리 / 북서울미술관 앞 소리'로 변경배포됨
마지막 QR 화면 자간과 텍스트 정리왼쪽은 QR과 안내, 오른쪽은 얇은 선으로 나눈 크레딧. 역할과 이름을 줄 맞춤. 크레딧 문구는 전달받은 그대로(한/영 각각)배포됨
달팽이 색이 한곳으로 몰리지 않게(무지개, 시작 지점 바꾸기)북서울 팔레트를 없애고 무지개로 변경. 관람객마다 시작 색을 무작위로 뽑고, ⑥ 편한 자리 결과만큼 색상환을 돎(1°마다 4°). 같은 색을 청감타워와 휴대폰 화면에도 보냄배포됨
검사 끝나고 달팽이가 포탈로 들어가기(청감타워와 연결)달팽이를 오른쪽으로 밀면 오른쪽에 포탈이 열리고 기어가 빨려 들어감. 청감타워에서 달팽이가 나오는 포탈과 같은 생김새배포됨

작가 곡 세 개가 아직 없어 윗줄 세 버튼은 북서울 녹음을 임시로 겁니다. 곡과 영상이 오면 경로만 바꾸면 됩니다.

3. QC 결과

3-1. 통과한 것

항목확인한 내용결과

3-2. 확인하지 못한 것

항목이유
아이패드 미니 5 실기기(사파리)자동 테스트는 크롬으로 돌림. 이 컴퓨터에 아이패드 시뮬레이터와 사파리 자동화가 없음
헤드폰 청취자동 테스트로는 소리를 들을 수 없음. 음량·음색·좌우 분리는 사람이 들어야 함
실제 휴대폰 카메라로 QR 찍기QR 그림 해독과 주소 열기까지만 확인
운영 Firebase 규칙과 저장소 파일의 대조권한 문제로 운영 규칙을 읽지 못함. 규칙 파일은 11/15 배포 뒤로 바뀌지 않음

4. QC에서 찾아 고친 버그 (미배포)

증상원인과 수정
페이지를 새로 연 뒤 첫 관람객의 달팽이 시작 색이 항상 빨강무작위 뽑기가 두 번째 관람객부터만 적용되고 있었음. 첫 관람객도 무작위로 뽑게 함
감상 화면에서 빈 곳을 누른 채 다른 손가락이 닿으면, 손을 뗀 뒤에도 '원래 소리'에 고정되고 슬라이더가 왼쪽 끝에 남음두 번째 손가락이 첫 손가락의 누르기를 다시 시작시켰음. 이미 손가락이 닿아 있을 때 더 닿는 손가락(손바닥, 옆 사람)은 무시하게 함
영어 ④ 껍질 얹기에서 A/B/C 글자가 두 줄 자막 위에 겹침글자 자리가 자막 길이를 고려하지 않았음. 자막이 길면 글자가 자막 아래로 내려가게 함
소리를 재생할 때마다 내부 오디오 부품이 지워지지 않고 쌓임(관람객당 8개 이상). 하루 종일 켜 두면 수천 개가 됨쓰는 소리 라이브러리가 재생 위치를 세는 부품을 매번 새로 만들고 지우지 않았음. 이 앱은 그 기능을 쓰지 않아 만들지 않게 막음. 재생 2,000회와 관람객 4명 연속에서 증가 0 확인, 소리에 걸리는 EQ 실측도 그대로

수정 뒤 한/영 전체 흐름, 멈춤 복구, 코드 왕복, 터치 테스트, EQ 실측을 다시 돌려 모두 통과했습니다. 이 네 수정은 아직 운영 서버에 올라가지 않았습니다.

5. 알고 있지만 그대로 둔 것

내용판단
① 편한 크기에서 빨간 화살표와 '큰 소리 / Loud' 글자가 안내 자막과 겹침. 영어는 항상, 한국어는 주소창이 보이는 높이에서. 화살표는 손을 대기 전까지만 보임그대로 두기로 함 (11/17 사용자 결정)
검사 화면 오른쪽 위의 작은 회색 디버그 숫자(①②③⑤)그대로 두기로 함 (11/17 사용자 결정)
영어 관람객 뒤에는 첫 화면이 영어로 남음. 음성은 켜짐으로 돌아가지만 언어는 초기화하지 않음의도인지 미확정

6. 작가 확인이 필요한 것

  • 국문 <전극 응답>의 영문이 'Adaptive Response'로 되어 있습니다. 전달받은 크레딧 그대로 넣었는데, 뜻이 달라 맞는지 확인이 필요합니다.
  • QR 화면 크레딧의 곡 순서(원우리 → 원우리 × 펠릭스 쿠빈 → 펠릭스 쿠빈)와 감상 버튼 순서(원우리 → 펠릭스 쿠빈 → 원우리 × 펠릭스 쿠빈)가 다릅니다. 크레딧은 전달받은 순서 그대로입니다.
  • 영문 크레딧의 'Interaction Design acornriver' 표기(국문은 '인터렉션 디자인 강민혁').
  • 감상을 시작하고 60초 뒤에 '청감타워로 보내 주세요' 안내가 뜹니다. 60초는 임시로 정한 값입니다.
  • 달팽이 색이 도는 정도(편한 자리 1°마다 색상 4°)와 무지개의 채도·밝기도 임시 값입니다.
  • Part 2 검사 결과(⑤⑥⑦⑧)는 지금 소리를 바꾸지 않고 달팽이·코드·분석 문구에만 쓰입니다. 소리에 반영할지는 정해지지 않았습니다.

7. 실기기에서 확인할 것

  • 포탈 연출의 속도와 크기, 무지개 색이 검정 배경에서 과하지 않은지
  • 감상 화면의 버튼 두 줄과 슬라이더 간격이 미니 5에서 누르기 편한지
  • QR을 실제 휴대폰으로 찍었을 때 자기 코드와 색으로 열리는지
  • 영상 여섯 개(약 158MB)를 미리 받아 두는데 아이패드 메모리가 버티는지
  • 하루 종일 켜 둔 뒤에도 소리가 끊기지 않는지(자동 테스트는 크롬 기준. 안전하게 개관 전에 한 번 새로고침하기를 권함)
  • 두두둥 음성과 드럼롤 효과음이 겹쳐 지저분하지 않은지
