# 결과 문구 작성용 표

관련 설명: [현재 결과 구조·숫자의 의미](result-copy-guide.md)

**이 파일을 복사해서 ‘작성할 문구’ 칸을 채워 주세요.** 고정 ID는 개발자가 문구를 연결하는 이름이므로 그대로 둡니다. 숫자와 선택 결과가 들어갈 자리는 `<...>`로 적습니다. 이 표의 초안이 자동으로 앱에 적용되지는 않습니다.

| 문서 정보 | 작성 |
| --- | --- |
| 버전 / 날짜 | [작성] |
| 작성자 | [작성] |
| 검토자 | [작성] |
| 작성할 언어 | [한국어 / 영어 / 둘 다] |
| 유형 제목 방식 | [현재 9가지 유지 / 새 제안] |
| 본문에 넣을 숫자 | [선택 횟수 / 높은 음 한계 / 기타 / 없음] |
| 한 화면 본문 구성 | [기본 추천: 소리 취향 + 높은 음 선택 + 음높이 응답, 총 3문장] |

운영 기준: **아이패드 가로 화면**, 이름 입력 없음, 검사 결과는 이번 체험의 선택을 설명함. 좋은 귀·나쁜 귀나 청력 진단으로 설명하지 않음.

## C. 높은 음을 고른 쪽 — 2갈래

이 검사는 어느 귀가 더 좋거나 실제 손잡이가 어느 쪽인지를 판정하는 문구로 쓰지 않습니다. **이번에 어느 쪽을 더 자주 골랐는지** 설명합니다.

허용 자리: `<높은음_선택횟수>`, `<높은음_전체횟수>`

숫자 예시: `3번 중 2번, 더 높은 소리를 오른쪽에서 골랐어요.`

## D. 음높이를 따라간 방식 — 3갈래

바탕음은 여기서 소리를 받쳐 주는 낮은 울림을, 배음은 그 위에 겹쳐지는 높은 울림을 설명하는 말로 풀어 쓸 수 있습니다. 어느 응답이 더 정확하거나 음악성이 좋다는 의미로 쓰지 않습니다.

| 고정 ID | 조건·의미 | 현재 한국어 | 작성할 한국어 | 작성할 영어 |
| --- | --- | --- | --- | --- |
| PITCH_F | 바탕음 응답 쪽으로 묶임 | 소리를 받쳐주는 낮은 바탕음을 따라 음의 움직임을 느끼는 편이에요. | [작성] | [작성] |
| PITCH_B | 두 응답이 함께 나타남 | 낮은 바탕음과 높은 울림을 함께 따라 음의 움직임을 느꼈어요. | [작성] | [작성] |
| PITCH_H | 배음 응답 쪽으로 묶임 | 소리 위로 겹쳐지는 높은 울림을 따라 음의 움직임을 느끼는 편이에요. | [작성] | [작성] |
