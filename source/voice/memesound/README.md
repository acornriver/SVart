# 밈사운드 안내 원본과 분할표 (2026-11-09)

- `snail_m_001.flac`: 전달받은 WAV의 24-bit / 44.1kHz / stereo PCM을 그대로 보존한 손실 없는 원본. WAV와 디코딩한 PCM의 SHA-256이 일치함을 확인했습니다.
- `instructions.pdf`: 전달받은 지시문 그대로입니다.
- `segments.json`: 29개 대사의 원본 시작·끝 시간, 자막, 개별 음량 보정량입니다. `originalSha256`은 전달받은 WAV 파일의 체크섬입니다.
- 재생 파일은 `media/voice/memesound/m<번호>.mp3`에 있습니다. 한국어 안내는 전부 이 파일을 사용하고, 기존 한국어 `media/voice/k/` 녹음은 제거했습니다. 이전 녹음은 Git 이력에서 복원할 수 있습니다.

## 재생성

레포 루트에서 `python3 scripts/split-memesound.py`를 실행합니다(ffmpeg와 ffprobe 필요). `--verify-only`를 붙이면 재생성 없이 파일 수·길이·디코딩을 검사합니다. 음성 인식 도구는 재생성에 필요하지 않습니다.

문장 경계는 지시문과 로컬 음성 인식 결과를 대조하고, 실제 무음 안에서 잘랐습니다. 음정·속도·말투·효과는 바꾸지 않고 gain만 조절했습니다. 인코딩한 29개 파일 모두 통합 음량 약 −27 LUFS로 검증했습니다.

## 앱에 반영한 지시문

- ① 시작 → 첫 쓸기에 소리 변화 안내 → 충분히 조절하고 멈추면 확정 안내.
- ②③ 시작 안내 → 조절 → 확정 안내. 이전 단계의 옛 결과 멘트는 재생하지 않습니다.
- ④ 시작 두 줄 → B(중음)·A(저음)·C(고음) → 다시 듣기·확정 안내 → 터치 허용. 사용자 최종 지시에 따라 왼쪽부터 A·B·C로 표시하고, 재생만 B·A·C로 합니다. 전달 PDF의 음역-문자 연결보다 이 지시가 우선합니다.
- ⑤ 오른쪽으로 밀어 8~20kHz를 조절하고 멈춤 → 다음 안내 → 달팽이 꾹으로 확정. 손을 떼기만 하면 조절값을 유지합니다.
- ⑥ 6-1 → 6-2 → 6-4(두 번) → 6-3 → 1초 뒤 검사. 두 번째 시행에는 음성 안내 없이 자막만 표시합니다.
- ⑦⑧ 한국어는 예시 없이 새 안내 다음 바로 3회·6회 검사를 진행하며, 시행 사이에 음성을 넣지 않습니다.
- 결과에서 완성 → 감사 → 세 소리 선택 안내를 재생합니다. 현재 main은 분석(완성·감사) → 달팽이 꾹 → 감상(세 소리 선택 안내)으로 나뉩니다. m9-3는 MUSIC 화면에 들어갈 때 재생합니다.

영어 새 녹음도 29개로 연결했습니다. 영어 원본·분할표는 `en/`, 재생 파일은 `media/voice/memesound/en/`입니다. `python3 scripts/split-memesound.py --lang en`으로 재생성합니다. 고역 5-2도 실제 영어 녹음으로 재생됩니다. 한/영 모두 새 순서를 사용합니다.

원본과 지시문, 재생 파일 모두 update 밖으로 옮기고 검증했으므로 `update/`는 더 이상 필요하지 않습니다.
