# 영어 밈 안내 원본과 분할표 (2026-11-09)

- `snail_m_002.flac`: 전달받은 `snail_m_002.wav`의 24-bit / 44.1kHz / stereo PCM을 손실 없이 보관했습니다. 원본 WAV 파일 SHA-256은 `segments.json`에 기록합니다.
- `instructions.pdf`: 새 영어 지시문 원본입니다.
- `segments.json`: 29개 대사의 원본 구간·자막·음량 보정량입니다. 녹음 끝의 약 24초 무음은 재생 파일에서 제외하고 원본에는 보존합니다.
- 재생 파일: `media/voice/memesound/en/m<번호>.mp3` (mono / 44.1kHz / 128kbps).

분할은 PDF와 로컬 Whisper 전사의 단어 시점을 대조하고 무음 안에서 정했습니다. 편집한 29개를 다시 전사해 대사가 해당 구간에 온전히 들어 있는지 확인했고, 인코딩 후 통합 음량은 약 −27 LUFS입니다. 속도·음정·말투는 바꾸지 않고 gain만 보정합니다.

PDF의 7-2 대사는 비어 있지만 통합 녹음에는 “Slide me toward the side where you hear the higher note.”가 있습니다. 이 녹음을 7-2로 사용하고 같은 자막을 표시합니다.

## 재생 흐름

한/영 모두 같은 m 번호와 새 흐름을 사용합니다. ⑥은 6-1 → 6-2 → 6-4(횟수) → 6-3 다음 1초 뒤 시작하고, 두 번째 시행에는 음성을 추가하지 않습니다. ⑦⑧은 예시 없이 새 안내 다음 3회·6회 검사로 들어갑니다. 고역 한계 5-2에도 새 녹음이 있어 자막만 표시하던 상태를 해소했습니다. 결과의 9-1·9-2는 분석 화면, 9-3은 음악 화면에서 재생합니다.

사용자 최종 지시가 PDF의 과거 표기보다 우선합니다. 화면 A(저)·B(중)·C(고), 최초 재생 B·A·C이며 달팽이는 항상 오른쪽을 봅니다. 이번 PDF의 효과음 추가 표기는 **사용자 선택에 따라 반영하지 않고 기존 배치를 유지**합니다.

## 재생성 / 검증

```sh
python3 scripts/split-memesound.py --lang en
python3 scripts/split-memesound.py --lang en --verify-only
node tests/e2e/flow.mjs /tmp/svart-en-fast en --fast
```

음원·실제 안내 시간이 바뀐 경우에는 `--fast` 없는 정상 속도 flow도 확인합니다. 예전 `media/voice/e/` 53개는 새 영어 녹음으로 대체하고 삭제했습니다. 이전 파일은 Git 이력에서 복원할 수 있습니다. 원본·지시문·분할표를 위 위치로 옮기고 PCM·PDF 동일성을 검증한 뒤 `media/update/`를 제거했습니다.

검증 완료: 한/영 빠른 flow, 영어 정상 속도 전체 flow, 영상·오디오 멈춤/오프라인 복구 모두 오류 없이 통과했습니다.
