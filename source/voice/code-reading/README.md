# 청감 코드 발음 음원

2026-11-17 전달된 `검사 결과`의 한국어 21개·영어 17개 원본을 `originals/`에 보존했습니다. 묶음 네 개를 단어 경계에서 분리해 한국어 24개·영어 26개 재생 파일을 만들었습니다. 원본 체크섬과 각 구간·바깥 무음 제거량·보정량은 `segments.json`에 있습니다.

- 한국어 `칠 팔 구 점`은 네 단위로 분리했습니다.
- 영어 `ee double you`는 E와 W로 분리하고 W의 `double you`는 통째로 유지했습니다.
- 영어 `two … nine`은 여덟 단위로, `point kilohertz`는 두 단위로 분리했습니다.
- 한국어 숫자 2와 5는 각각 E(이), O(오) 파일을 공유합니다. 영어 O와 숫자 0은 각각 oh와 zero입니다.

경계는 단어별 음성 인식과 스펙트로그램을 대조해 정했습니다. 짧은 발음의 음량은 동일 단위를 8초 동안 반복해 측정했습니다. 음정·속도는 유지하고 개별 gain으로 약 −27 LUFS, −3 dBTP 이하로 맞췄습니다. 양 끝 2ms 페이드로 연결 시 클릭을 줄였습니다.

## 재생성·검증

```sh
python3 scripts/prepare-code-voice.py
python3 scripts/prepare-code-voice.py --verify-only
node tests/earcode/voice.mjs
node tests/e2e/code-voice.mjs /tmp/svart-code-voice
```

`hearingCodeVoice.js`가 완성된 코드의 여섯 글자, 주파수 숫자와 소수점, 킬로헤르츠, 음량 숫자를 순서대로 읽습니다. 주파수는 8.0~20.0kHz, 음량은 0~9를 지원합니다. 알 수 없는 결과(`·`, `–`)는 읽기를 건너뛰고 보고서로 진행합니다.

결과 코드가 크게 보이는 동안 효과음이 끝나면 읽고, 읽기가 끝난 뒤 분석 목록을 보여 줍니다. 기존 안내와 같은 음소거·볼륨·①에서 고른 크기를 따릅니다. 새 요청, 언어 변경, 단계 이동, 다시 시작은 재생을 취소합니다. 필요한 파일을 모두 읽은 뒤 첫 발음을 시작하며, 읽기 실패 시에도 보고서 흐름은 계속됩니다.

588,060개 코드의 한·영 계획 1,176,120개와 재생 파일 50개를 자동 검증합니다. 실제 헤드폰 청취 평가는 별도로 필요합니다.

한/영 빠른 전체 흐름과 멈춤 복구 검사를 2026-11-17에 통과했습니다. 전체 안내 62개도 디코딩·길이·약 −27 LUFS·피크 여유를 검증했습니다. 코드 발음 50개는 반복 측정 −27.0 LUFS, 최대 −5.6 dBTP입니다.

정상 속도로 한/영 각 4개 코드의 재생 시간·발음 사이 간격을 확인했고, 재생 교체·음소거·언어 변경·다시 시작·단계 이동 및 파일 누락·로딩 중 취소 검사를 통과했습니다.
